# Labs

Bac à sable personnel pour expérimenter autour des API, de l'event-driven et de l'IA.

## Règles

- Aucun contenu client ni professionnel.
- Aucun secret commité : stocker les valeurs locales dans `.env` (ignoré par Git) et documenter les variables nécessaires dans `.env.example`.
- Une expérience = un dossier avec son propre `README.md`, qui précise l'objectif, le résultat et ce que j'en retiens.
