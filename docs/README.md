# Le Brief

Site de lecture des veilles Fintech et IAM/Cyber. `index.html` contient les 10 éditions initiales et charge `editions.json` depuis le même répertoire sur le site publié. Les états de lecture et quiz restent dans le navigateur (localStorage).

Les tâches ChatGPT écrivent chaque nouvelle édition dans `docs/editions.json` en préservant les entrées précédentes et les deux catégories. GitHub Pages doit servir la branche main et le dossier /docs. Le dépôt est privé : la disponibilité de GitHub Pages dépend du plan et des paramètres du dépôt.
